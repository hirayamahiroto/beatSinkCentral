# 候補者リスト（テンプレート）

> ベータ参加者（5〜8 人）を選ぶための候補者リスト。条件は [`prd.md`](../../../discussions/prd/know-to-support-verification/prd.md) §7-1・§2-5 に従う。
> **時限ドキュメント**（[`plan.md`](../plan.md) の T11）。実名・連絡先はこのリポジトリに書かない（候補者ごとに仮 ID を振り、対応表は運営の手元に置く）。

---

## 1. 使いどころ

- 週 0 の声かけ前に埋め、**10 名超・複数コミュニティ・友人に偏っていない**の 3 条件を満たしてから声かけに進む
- 聞き取り①（[`interview-scripts.md`](./interview-scripts.md) §2）で本人の意向を確認し、「参加」列を確定する
- 確定した参加者は [`translation-assignment.md`](./translation-assignment.md) へ転記する

## 2. 条件（PRD §7-1・§2-5）

| #   | 条件                                           | 判定のしかた                                                                                        |
| --- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| C1  | 中堅層である                                   | 数字（月 1 本以上の出演・フォロワー数百〜数千）は目安。**「外に出たいが公式を持てていない」**で判定 |
| C2  | シーンの外（大衆）に届きたいと**明言**している | 本人の発言・投稿から。推測で○にしない。未確認なら「?」にして聞き取り①で確かめる                     |
| C3  | 直近 3 か月にライブ告知をした                  | SNS の投稿で確認できる                                                                              |
| C4  | 次の 3 か月にライブ予定がある                  | 本人に確認。ベータ期間中に告知が 1〜2 回入ることが前提                                              |
| C5  | 有名層・新人層ではない                         | 自前の媒体（公式サイト・事務所）を持つ → 有名。ライブ経験数回以下 → 新人                            |

列の書き方:

- 所属コミュニティ: 地域（例: 関東／関西／地方都市名）と大会系統（例: 出場している大会・所属クルー・活動拠点のイベント）を分けて書く。同じ値が並ぶほど「複数コミュニティ」から外れる
- 運営との関係: `友人` / `知人` / `知人の紹介` / `面識なし` の 4 段階
- C1〜C5: `○` / `×` / `?`（未確認）。`?` が残るまま声かけしない
- 声かけ: `未` / `済` / `辞退`。参加: `○` / `×` / `保留`

## 4. 偏りチェック（声かけ前に埋める）

| 観点                     | PRD §7-1 の要求                                        | 現状の値 | 満たすか |
| ------------------------ | ------------------------------------------------------ | -------- | -------- |
| 候補の人数               | 10 人を超える（参加は 5〜8 人）                        |          |          |
| 地域コミュニティの数     | 複数                                                   |          |          |
| 大会系統コミュニティの数 | 複数                                                   |          |          |
| 「友人」の割合           | 友人だけにしない（好意で動くと課題の有無が分からない） |          |          |

> **案**（PRD に数値の規定なし）: 「複数」は 2 以上、「友人だけにしない」は参加者の中で `友人` が過半数を超えない、を目安にする。満たさない場合は候補を広げてから声かけする。

## 5. 参加者の確定

- 参加 `○` が 5〜8 人になった時点で締める。10 人を超えると個別に話を聞けない（§7-1）
- 確定日と人数をここに残す: 確定日 `____`、人数 `__`
