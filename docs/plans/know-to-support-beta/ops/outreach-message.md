# 声かけ文面

> ベータ参加を依頼するときの文面。依頼は [`prd.md`](../../../discussions/prd/know-to-support-verification/prd.md) §7-2 の **3 つだけ**に絞り、§7-6 に従って**見本 Story を渡さない**。
> **時限ドキュメント**（[`plan.md`](../plan.md) の T11）。

---

## 1. 使いどころ

- 週 0、[`candidate-list.md`](./candidate-list.md) の偏りチェックを通した候補者に送る
- 送る手段は候補者と普段使っている連絡手段（DM 等）でよい。文面は手段に合わせて短くしてよいが、§3 の「言わないこと」は守る

## 2. 文面

```
〇〇さん

beatfolio という、アーティストが自分のページを持てるサービスを作っています。
「シーンの外の人に、自分のことを知ってもらって、ライブに来てもらう」ための場所です。

いま 6〜8 週間のベータをやっていて、〇〇さんに参加してほしいと思っています。
お願いしたいことは 3 つだけです。

1. 3 つの問いに答えて、自分のことを書く（始まり／転機／何を表現したいのか）
2. 次のライブを「オファー」として入れる（日付・場所・チケット URL・一言・共演者）
3. 次のライブの告知に、ページの URL を貼る

こちらでやることは、ページの用意、告知に貼れる縦画像、毎週の数字の共有（何人が開いて、どこまで読んで、何人がライブ情報を踏んだか）です。

始める前に一度、30 分ほど話を聞かせてください（いまの活動や、お客さんのことなど）。
書いている途中・告知の後にも、短く感想を聞かせてもらえると助かります。

参加してもらえそうなら、都合の良い日時を教えてください。
```

## 3. 言わないこと（§7-6）

| 言わない                                   | 理由                                                                                                                                    |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 他の人が書いた Story・書き方の例           | 見本があると全員が寄せて書き、問いの設計が良いのか見本が良いのか分からなくなる                                                          |
| 「こう書くと良い」という文章の指導         | 同上。問いは 3 つ渡すだけにする                                                                                                         |
| 見た目・デザインへの意見の依頼             | 供給と応援の検証が薄まる                                                                                                                |
| 翻訳段落の有無（あり群／なし群のどちらか） | 割り付けは [`translation-assignment.md`](./translation-assignment.md) で開始前に固定し、本人には翻訳の下書きを送る段階で伝える（同 §3） |

## 4. 質問されたときの答え方

| 聞かれること           | 答え                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| 何を書けばいいか       | 3 つの問いに、自分の言葉で答えてもらえれば十分。長さ・上手さは気にしなくてよい                   |
| 例を見せてほしい       | 例は渡さない。「問いだけで書けるか」を確かめたい、と正直に伝える                                 |
| 数字は何が見えるのか   | §7-3 の 4 つ（開いた人数／読んだ割合／オファーを踏んだ人数／ビートボクサー以外の割合）を毎週返す |
| 参加をやめたくなったら | いつでも抜けてよい。書いた内容を残すか消すかは本人が選べる                                       |

> **案**（PRD に規定なし）: 「参加をやめたくなったら」の扱いは運営の約束として文面に含めてよい。Story の削除はベータ中は運営が手で対応する。
