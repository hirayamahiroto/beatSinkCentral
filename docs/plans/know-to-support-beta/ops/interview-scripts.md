# 聞き取りスクリプト ①開始前・②執筆直後・③告知後

> 数字は「起きたか」、話は「なぜか」。話の側を取りこぼさないためのスクリプトと記録形式。問いは [`prd.md`](../../../discussions/prd/know-to-support-verification/prd.md) §7-5、追加の 2 問は [`concept-and-loops.md`](../../../discussions/prd/know-to-support-verification/concept-and-loops.md) §6-2（PRD §7-5 に反映済み）。
> **時限ドキュメント**（[`plan.md`](../plan.md) の T11）。記録は仮 ID で残し、実名・連絡先・収入の生の金額はこのリポジトリに書かない。

## 1. 共通の進め方

| 項目     | 内容                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 時間     | ① 30 分、② 15 分、③ 20 分を目安にする                                                                                              |
| 手段     | 通話でも対面でもよい。テキストだけの回答は「なぜか」が薄くなるので避ける                                                           |
| 聞き方   | 問いは順番どおりに読み上げてよい。答えが短ければ「具体的には？」「最近だと？」で一段掘る。誘導しない（見本を渡さない §7-6 と同根） |
| 聞かない | 見た目・デザインの意見（§7-6）。本人から出たら記録はするが、追加で掘らない                                                         |
| 記録     | 聞き取りの当日中に §2〜§4 の記録欄へ書く。発言はできるだけ本人の言葉のまま残す                                                     |

「仮説の判定」の付け方:

| 判定   | 付ける条件                                                                                               |
| ------ | -------------------------------------------------------------------------------------------------------- |
| 支持   | 答えが §2-1・§2-5・concept-and-loops §2 の記述と同じ方向（例: Q1-1 で同業が過半／Q1-5 で送るものが無い） |
| 不支持 | 答えが逆方向（例: Q1-1 で外の人が過半／Q1-5 で自前の公式媒体を送っている）                               |
| 不明   | 本人が答えられない・数字を持っていない。**不明を支持に寄せない**                                         |
