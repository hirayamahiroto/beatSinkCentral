# 貼り方の依頼文

> 3 枚の画像と一緒に本人へ送る文面。`【…】` を埋めて送る。依頼は PRD §7-2 の 3 つ目「次の告知にページの URL を貼る」だけに絞り、見本の Story や書き方の指示は足さない（§7-6）。

## 送る文面

```
【名前】さん

【日付】のライブ用に、ストーリーズ用の画像を 3 枚作りました。
順番に投稿してもらえると、見た人がそのままページに届きます。

■ 画像（添付の 3 枚）
1 枚目: 【名前】さんの紹介
2 枚目: 「この人の何が凄いか」の一行
3 枚目: ライブの案内と、ページの QR

■ 貼り方
1. ストーリーズに 1 → 2 → 3 の順で連続投稿してください
2. 3 枚目に「リンク」スタンプを付けて、下の URL を貼ってください
   （QR だけだとスマホから飛べないので、リンクスタンプが本命です）
3. 3 枚を「ハイライト」にまとめて、ライブ当日まで残しておいてください
4. できれば、プロフィールの bio のリンクも同じ URL にしてください

■ URL（このままコピーしてください。末尾の ?from=announce まで含めて 1 つの URL です）
https://<host>/players/<handle>?from=announce

文言や画像は変えてもらって構いません。
変えた場合は、どこを変えたかだけ教えてください。
貼るときに迷ったこと・貼らなかった理由があれば、それも聞かせてください。
```

## 置き場所ごとの要点（送る側の控え）

| 置き場所     | 依頼の要点                                         | なぜ                                                             |
| ------------ | -------------------------------------------------- | ---------------------------------------------------------------- |
| ストーリーズ | 1→2→3 の順に連続投稿。3 枚目にリンクスタンプで URL | 3 枚の順がページの区画順（引っかかり → 翻訳 → オファー）と同じ   |
| ハイライト   | 3 枚をライブ当日まで残す                           | ストーリーズは 24 時間で消える。当日までの到達を切らさない       |
| bio          | プロフィールのリンクを同じ URL にする              | H1'（公式として扱うか）の観測点。置いたかどうかを聞き取り③で確認 |

- 「変えてもらって構わない」は本気で言う。変えた内容は [`reaction-log.md`](./reaction-log.md) の「文言」列に残し、文言ごとの反応差を見る
- 貼らなかった人には理由を聞く（§7-2「3 をやらない人がいれば、それが最大の学び」）。催促はしない
