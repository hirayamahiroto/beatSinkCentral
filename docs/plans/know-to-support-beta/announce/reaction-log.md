# 素材別・文言別の反応の記録シート

> PRD §8 月 2 の判断（H2 が不成立なら F6 を強化する）に使う。「どの素材の・どの文言が・どこに貼られて・外の人を何人連れてきたか」を 1 行 1 素材で残す。数字は [`README.md`](./README.md) の週次 SQL から転記し、話は聞き取り③から転記する。

## 記録の単位

- 1 行 = 1 人 × 1 ライブ告知 × 1 素材種別 × 1 貼った場所
- 同じ人が文言を変えて貼り直したら行を分ける（文言差を見るため）
- `profile_view (from=announce)` は人単位でしか取れない。複数行に同じ人が並ぶときは合計を各行に書き、「文言」「貼った場所」の違いは聞き取りと Instagram 側のインサイト（閲覧数・リンククリック数）で補う

列の値:

- 素材種別: `①引っかかり` / `②翻訳の一行` / `③オファー+QR` / `本人が作った別素材`
- 貼った場所: `ストーリーズ` / `ハイライト` / `bio` / `その他（主催者へ送付 等）`
- IG 閲覧数・リンククリック: 本人に Instagram のインサイトを見せてもらう（任意。取れなければ空欄）
- 外の人率: T08 の `survey_answer` から（README の SQL）。分母が 5 未満なら率にせず生の数だけ書く

## 月 2 の判断に使う見方

| 見えたこと                              | 読み                                       | 次の手                                                                  |
| --------------------------------------- | ------------------------------------------ | ----------------------------------------------------------------------- |
| `from=announce` が来ていない            | 貼られていない、か、貼っても踏まれていない | 「貼った日」（url-sheet）を先に見る。貼っていれば文言・置き場所を変える |
| 来ているが外の人率が低い                | 告知の届き先が内輪（H2 不成立）            | F6 を強化する。文言別の行を比べ、外の人率が高い文言・素材種別に寄せる   |
| ②翻訳の一行を載せた人だけ外の人率が高い | 翻訳（H4）が発見に効いている可能性         | 翻訳あり群の数を増やす判断材料にする（§8 月 3）                         |
| 本人が作った別素材の方が反応が良い      | テンプレートの型が合っていない             | その素材を次のテンプレートの元にする。生成機能はまだ作らない            |
