# T07: 聴きどころ（動画 1 本＋一言）

| 項目 | 内容              |
| ---- | ----------------- |
| 対応 | F4, H3 / PRD §5-1 |
| 種別 | 作る              |
| 依存 | T00               |
| 規模 | S                 |

## 背景

「行けば分かる」への橋（PRD §2-2）。動画 URL 1 本と「ここを聴いて」の一言。埋め込みで可。

## スコープ

### やること

- **DB**: 動画 URL ＋ 一言のフィールド追加（1 本のみ。複数化はしない）
- **URL の種別はマスタ参照の方針に従う**: 埋め込み対応プラットフォームの判定を URL からの推定に頼らない設計にする（checklist §14-1「種別を保存し、推定で復元しない」）。ベータは YouTube のみ対応で開始してよいが、種別を保存する形にしておく
- **編集画面**: URL と一言の入力（本人）
- **表示**: 埋め込みプレイヤー＋一言（§5-2 順 4）。未入力なら区画ごと非表示

### やらないこと

- 複数動画・プレイリスト
- 動画のアップロード・ホスティング（外部埋め込みのみ）

## 受け入れ条件

- [ ] 対応プラットフォームの動画が詳細ページに埋め込み表示される
- [ ] 不正・非対応 URL は保存時に型付きエラーで弾かれる（`?? フォールバック`で握りつぶさない）
- [ ] 未入力のプロフィールで区画が描画されない
- [ ] VO（URL 検証）にテストがある

## 着手前に決めること

- 対応プラットフォームの初期セット（YouTube のみか、＋Instagram/TikTok か）
