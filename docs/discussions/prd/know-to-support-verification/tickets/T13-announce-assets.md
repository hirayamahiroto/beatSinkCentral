# T13: 告知素材（縦画像 3 枚 × 人数分）

| 項目 | 内容                             |
| ---- | -------------------------------- |
| 対応 | F6, H1, H2 / PRD §5-1, §7-3      |
| 種別 | 手作業（運用）                   |
| 依存 | T08（ページが公開されてから）    |
| 規模 | M（人数分 × ライブ回数分の反復） |

## 背景

「貼ってもらう」（H1）と「外の人に届く」（H2）の間を繋ぐ素材。Instagram ストーリーズ用の縦画像 3 枚を運営が手で作る。**生成機能は作らない**（PRD 原則: 機能化は手作業で効くと分かってから）。

## スコープ

### やること

- 縦（9:16）3 枚構成のテンプレートを 1 セット設計する（例: ①引っかかり（写真＋一文）②翻訳の一行 ③オファー＋URL/QR）
- 各参加者 × 各ライブ告知ごとに 3 枚を作成し、**人ごとの参照元付き URL（`?from=announce`）** を載せる
- 貼り方の依頼文（ストーリーズ・ハイライト・bio への置き方）をセットで渡す
- 何を変えたら反応が変わったか（文言・写真・順序）を週次の返し（T14）と突き合わせて記録する

### やらないこと

- 画像生成の自動化・テンプレートエンジン
- リール動画・長尺素材（縦画像 3 枚に固定して比較可能性を保つ）

## 受け入れ条件

- [ ] テンプレート 1 セットが存在し、1 人あたり 30 分以内で 3 枚を量産できる
- [ ] 全素材の URL に `?from=announce` が付いている
- [ ] 素材別・文言別の反応の記録が残っている（H2 不成立時に F6 を強化する判断材料。§8 月 2）
