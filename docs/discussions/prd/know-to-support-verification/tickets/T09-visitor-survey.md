# T09: 一問アンケート（ビートボクサー判定）

| 項目 | 内容              |
| ---- | ----------------- |
| 対応 | F5, H2 / PRD §6-1 |
| 種別 | 作る              |
| 依存 | T02, T08          |
| 規模 | S                 |

## 背景

H2（大衆到達）の判定材料「非ビートボクサー率」の唯一の取得手段。`?from=announce` の流入に「ビートボックスをやっていますか」を一問だけ聞く（PRD §4 H2）。

## スコープ

### やること

- 詳細ページ上の一問 UI（はい／いいえの 2 択のみ。設問文はドメイン語彙でないため UI コピーとして持ってよい）
- 回答で `survey_answer`（`is_beatboxer: boolean`）を `track()` 経由で送る
- 表示条件: `from=announce`（必要なら `share` も）での訪問時。同一訪問者への再表示を抑制（回答済みはローカルに記録。取得失敗時も壊れない try/catch）
- 未回答・スキップを許容する（回答は強制しない）

### やらないこと

- 回答の保存を専用テーブルにすること（`analytics_events` の props で足りる）
- 属性の追加質問（年齢・きっかけ等）。一問に絞るのが設計意図

## 受け入れ条件

- [ ] 回答が `survey_answer` として `is_beatboxer` 付きで記録される
- [ ] 回答済みの訪問者に再表示されない（ストレージ不可環境でも表示が壊れない）
- [ ] 閲覧の邪魔をしない（未回答でもページ全体が読める）
